The project combines **data visualization, business intelligence and premium UI/UX design** to transform vehicle sales data into an interactive analytical experience.

## 🎯 Project Objective

The main objective of this project is to create an interactive dashboard capable of transforming vehicle sales data into actionable business insights.

The dashboard was designed to answer key business questions such as:

- Which Porsche models have the highest sales volume?
- Which models are most popular in each city?
- Which model year had the highest number of sales during the analyzed period?
- Which states generate the highest sales volume?
- How have sales evolved over time?
- Which payment methods are most commonly used?
- What are the main sales patterns by location and vehicle model?

---

## ✨ Main Features

### 🚗 Sales by Porsche Model

Visual analysis of the most frequently sold Porsche models.

The dashboard allows users to quickly identify the vehicles with the highest sales volume.

---

### 📍 Sales by City

Analysis of vehicle sales according to the customer's city.

This visualization helps identify regional preferences and the most popular Porsche models in different locations.

---

### 🗺️ Sales by State

Sales distribution across Brazilian states.

This provides a broader geographic perspective and makes it possible to identify the regions with the highest sales concentration.

---

### 📅 Model Year Analysis

Comparison of sales performance by vehicle model year.

This allows users to identify which model years generated the highest sales volume during the selected period.

---

### 📈 Sales Evolution

Interactive visualization showing the evolution of sales over time.

This analysis helps identify:

- growth trends;
- decreases in sales;
- seasonal patterns;
- changes in demand.

---

### 💳 Payment Method

Analysis of sales according to the payment method selected by customers.

The dashboard provides visibility into the distribution between different payment options.

---

## 🎛️ Interactive Filters

The dashboard includes interactive filters that allow users to dynamically explore the data.

Available filters include:

| Filter | Description |
|---|---|
| 🚗 Porsche Model | Filter sales by vehicle model |
| 📅 Model Year | Filter by vehicle model year |
| 📍 City | Filter sales by city |
| 💳 Payment Method | Filter by payment method |

The visualizations automatically update according to the selected filters.

# 🎨 UI/UX Design

The interface was designed with a focus on a **premium, minimalist and refined automotive experience**.

The visual concept was inspired by the digital experience of Porsche Brazil:

🔗 https://www.porsche.com/brazil/pt/

### Design principles

- Minimalist layout
- Premium visual language
- Strong typography hierarchy
- High contrast
- Generous spacing
- Automotive-oriented visual elements
- Responsive layout
- Data-focused interface
- Clear information hierarchy

The goal was not to reproduce Porsche's website, but to create an **original dashboard inspired by its premium design language**.
